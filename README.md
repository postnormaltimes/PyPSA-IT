# PyPSA-IT

PyPSA-IT is a research project for modelling Italian electricity markets and power-system operation with PyPSA.

- **[Zonal](Zonal/README.md)** is the currently implemented hourly model of Italy's seven bidding zones. It covers fixed-capacity 2040 and 2050 scenarios, thermal unit commitment, storage, hydro and external-market interfaces.
- **[Nodal](Nodal/README.md)** is the more detailed model family to be developed here, retaining physical network topology and nodal balances.

Each model has its own inputs, environment and documentation. For the implemented model, enter Zonal and follow its [reproducibility guide](Zonal/docs/REPRODUCIBILITY_GUIDE.md).
