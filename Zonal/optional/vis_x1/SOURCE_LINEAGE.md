# Visualization source identity

The retained modules originate from the accepted PyPSA visualization toolkit and model adapters. The original source identity, component hashes and geographic support hashes are preserved in HANDOFF_MANIFEST.json. Toolkit source files remain unchanged. Original package documentation is retained in the research evidence archive; the installation documentation here describes the portable subset.

The included Natural Earth country context is public-domain data. Optional NUTS2 geometry is a separately verified presentation input and has no role in dispatch or price recovery.
