# Plotting geography

`naturalearth_lowres.geojson` contains 177 Natural Earth country features in
geographic EPSG:4326 / GeoJSON CRS84. Natural Earth is public domain. This
coarse context layer is used only for maps, not for market-zone polygons or
transmission constraints.

The source release version is not specified by the original supplied dataset.
SHA-256: `c83795a6615b793401ac04d642792d9a2fb11d3a8392fd9908b81805d7e9a114`.
The plotting package resolves the file relative to its own directory. More
detailed GISCO boundaries must be supplied separately under their source terms.
