# Single-case simulation runbook

From `Zonal/`, create the locked environment and restore `zonal-production-data-v3` as described in [Reproducibility](REPRODUCIBILITY_GUIDE.md). Configure a valid Gurobi licence locally, outside the repository and release staging.

Select one year and scenario explicitly. Valid final pairs are 2040/`final_v3` and 2050/`final_v6`, each Slow/Base/High. The wrapper is:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\run_final_case.ps1 -Year 2040 -Scenario Base
```

The sequence is `preflight` → `run-reference` → `verify-reference` → `run-uc` → `verify-uc` → `run-price` → `verify-price` → `report` → `final-qa`. All use `python -m mem_model.stage_b_uc2 <action> --year <year> --scenario <scenario> --variant <version>`.

Actions are same-case and fail closed. Existing different results are not overwritten. If a step fails, retain its receipts and inspect the condition before issuing the next explicit action. Do not bypass a missing prerequisite, substitute an older solved case, or change YAML merely to obtain a solve.

Reference LP output is a diagnostic comparison. UC MILP output supplies physical dispatch, commitment, storage, flows and shedding. Fixed-commitment LP duals supply prices and water values; its primal dispatch does not replace UC physical operation. `report` and `final-qa` consume verified same-case results.

Outputs are under `results/final_methodology_v3/2040/<scenario>` or `results/final_methodology_v6/2050/<scenario>`. Published results are installed separately under `data/research_results/`; they do not satisfy a new simulation's same-case run dependencies.
