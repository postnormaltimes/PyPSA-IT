# Research evidence

Source registers, extraction tables, manageable workbooks and fleet/scenario derivations in this directory document the academic basis of the model. Current executable assumptions are specified in the methodology and scenario governance documents. Historical research has evidentiary status and does not override current controls.

Large sources and original historical specifications are retained in a separate research-evidence package. It is not required for either execution path.
